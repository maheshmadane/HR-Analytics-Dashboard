## HR Analytics Dashboard
### 1. Short Description

-Built an interactive HR Analytics Dashboard using Power BI to analyze employee data, track workforce trends, and generate insights on performance and job satisfaction.

### 2. Tech Stack
-Power BI
-Excel
-Data Modeling
-DAX
-Power Query

### 3. Data Source
-Dataset collected from Kaggle (HR Employee Dataset)

### 4. Features / Highlights
-Employee distribution by department, gender, and job role
-Job satisfaction and performance analysis
-Interactive dashboard with slicers and filters
-KPI cards for quick insights
-Data cleaning and transformation using Power Query

### 5. Example Insights
-Identified departments with higher employee count
-Analyzed job satisfaction trends across job levels
-Found patterns in employee performance and engagement
